# Security Policy

## Metadata and purpose
Local version 1.0, English edition. Approved by Diego Aguirre for **personal documentary governance**. This is not a completed security audit, a GitHub repository setting, an operational access-control list, or an external certification.

## Classification and permissions
`raw/` may contain private information. Grant access only to the owner and explicitly authorized collaborators. Separate public from restricted material; review before publishing to the public repository. Diego Aguirre identifies himself as owner; additional collaborators and any configured access controls remain **NOT_RECORDED**.

## GitHub security
A public repository [Diiegoal/memoria-externa](https://github.com/Diiegoal/memoria-externa) exists, but this English ZIP has **not** been pushed by this operation. Branch protection, real enforcement of CODEOWNERS, MFA status, mandatory reviews, and secrets are **NOT_VERIFIED**. If publishing, favor least privilege, reviewed pull requests, branch protections, and prior approval. `.gitignore` cannot undo sensitive data already committed.

## Protecting originals
Disk encryption and backups outside the repository remain **NOT_CONFIGURED** by this ZIP. Review personal data and secrets when exporting; never silently truncate raw originals. If sensitive personal information is discovered, limit distribution and obtain explicit consent before sharing.

## Threat model
Unauthorized access to the ZIP or raw documents; accidental public `git push`; prompt injection through supplied documents; stale search indexes; loss of originals; undocumented changes to decisions; and overclaiming approvals. The included Python scripts operate locally and do not require network credentials.

## Incident response
Stop distribution, assess exposure, revoke compromised credentials, restore a genuine clean copy, rerun integrity and index checks, and document what really occurred. No rehearsed incident response capability is claimed.
